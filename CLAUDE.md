# Жастар — правила проекта

Мобильное приложение молодёжного ресурсного центра «Жастар» (Кызылорда, Казахстан).
iOS + Android. Интерфейс двуязычный: казахский и русский.

---

## Стек

- React Native 0.86 + Expo SDK 57
- TypeScript strict
- Expo Router (file-based routing, корень маршрутов — `src/app`)
- NativeWind v4 для стилизации
- Supabase — auth + PostgreSQL
- Zustand — глобальное состояние

Версии SDK не понижать и не обновлять без явного указания.

---

## Структура

```
src/
  app/                   только экраны и layout'ы Expo Router
    (auth)/              вход, регистрация, восстановление
    (tabs)/              index, qr, menu, notifications, profile
  components/            переиспользуемые компоненты
    ui/                  примитивы: Button, Card, Badge, Avatar
    navigation/          CustomTabBar и прочая навигация
  services/              вся работа с сетью и Supabase
  hooks/                 кастомные хуки
  constants/             theme.ts, config.ts
  types/                 общие типы, типы БД
```

Бизнес-логику и запросы в `src/app/` не размещать — там только композиция экрана.

Шаблонные компоненты (`themed-text.tsx`, `themed-view.tsx`, `hint-row.tsx`, `web-badge.tsx`, `collapsible.tsx`, `external-link.tsx`) — демо-наследие Expo. Не развивать их и не использовать в новых экранах; удалять по мере замены собственными.

---

## Код

- Только функциональные компоненты. Классы запрещены.
- Только TypeScript. `any` запрещён — при неизвестном типе `unknown` с последующим сужением.
- Компоненты — `PascalCase`, файлы компонентов — `PascalCase.tsx`.
- Хуки — `use` + `PascalCase`.
- Стилизация только через `className` (NativeWind). `StyleSheet.create` не использовать.
- Hex-цвета в JSX запрещены. Все цвета — из `src/constants/theme.ts` и Tailwind-классов.
- Списки — через `FlatList`/`FlashList`, не `.map`. `renderItem` выносить из тела компонента.
- Строки интерфейса не хардкодить в JSX — выносить в i18n (kk/ru).

---

## Данные

- Все запросы — в `src/services/`, каждый возвращает типизированный результат.
- Ошибки не глотать: сервис возвращает `{ data, error }`, экран отображает состояние.
- Каждый экран с данными обрабатывает три состояния: `loading`, `empty`, `error`.
- Серверное состояние не дублировать в Zustand — Zustand только для UI-состояния и сессии.

## Безопасность

- В приложении только `EXPO_PUBLIC_SUPABASE_URL` и `EXPO_PUBLIC_SUPABASE_ANON_KEY`.
- Ключ `service_role` в коде приложения запрещён категорически. Операции, требующие
  привилегированного доступа, — только на backend или в Edge Functions.
- Любая таблица создаётся сразу с включённым RLS и явными политиками.
  Политика вида `using (true)` равносильна отсутствию защиты и не принимается.
- Токены сессии — в `expo-secure-store`, не в `AsyncStorage`.
- `.env` в `.gitignore`. Ключи не коммитить, не вставлять в `app.json`.

## Дизайн

Источник истины — макеты в `design_handoff_jastar_mobile/`
(`Jastar-iOS_dc.html`, `Jastar-Android_dc.html`), шесть экранов для каждой платформы.

Палитра:

| Токен | Значение |
|---|---|
| primary | `#15B364` |
| primaryDark | `#0E8A4B` |
| primarySoft | `#DCFCE7` |
| orange (мероприятия) | `#FB8B2D` |
| blue (гранты) | `#1E63DA` |
| ink | `#0E1512` |
| muted | `#6B7770` |
| subtle | `#9AA59D` |
| surface | `#F3F5F1` |
| border | `#E6EAE4` |

Шрифты: Space Grotesk (заголовки), Manrope (основной текст).

Значение `#22c55e` устарело, не использовать.

Нижняя навигация кастомная и различается по платформам: плавающая «таблетка» на iOS,
панель Material 3 на Android. Системный таб-бар (`NativeTabs`) не использовать.

`src/constants/theme.ts` содержит шаблонный объект `Colors` (light/dark), на который
ссылаются `use-theme.ts` и `use-color-scheme.ts`. При добавлении токенов проекта
существующие экспорты не ломать — расширять файл, а не перезаписывать.

## Окружение

- Windows + PowerShell. Пути с круглыми скобками брать в кавычки: `cd "src/app/(tabs)"`.
- Запуск на устройстве через Expo Go. `expo-dev-client` и EAS пока не ставить.
- Проверка перед сдачей задачи: `npx tsc --noEmit` и успешный старт Metro.

## Git

- Ветки: `feature/<название>`, `fix/<название>`.
- Прямой push в `main` закрыт — только pull request.
- Коммиты на русском, conventional commits: `feat: экран новостей`, `fix: отступы таб-бара`.
- Не коммитить без явного указания.

  и показать ошибку, а не обходить её самостоятельно.
