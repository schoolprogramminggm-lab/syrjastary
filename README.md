# Жастар — мобильное приложение молодёжного ресурсного центра

Мобильное приложение молодёжного ресурсного центра «Жастар» (Кызылординская область, Казахстан). Единая точка доступа к мероприятиям, грантам, программам и сервисам центра для молодёжи региона.

## О проекте

Приложение даёт молодёжи региона доступ к возможностям центра с телефона: лента новостей и анонсов, каталог грантов и программ, регистрация на мероприятия через QR-код, персональный профиль с историей участия.

**Статус:** ранняя стадия разработки. Каркас проекта и дизайн-система готовы, экраны в работе.

---

## Возможности

| Раздел | Описание |
|---|---|
| **Басты бет** | Лента новостей, анонсов мероприятий и грантовых конкурсов |
| **QR** | Сканер для регистрации на мероприятиях и подтверждения участия |
| **Мәзір** | Каталог разделов: программы, гранты, обучение, волонтёрство |
| **Хабарламалар** | Push-уведомления о новых возможностях и статусе заявок |
| **Профиль** | Личные данные, история участия, достижения |

Интерфейс двуязычный: казахский и русский.

## Технологический стек

**Мобильное приложение**

- React Native 0.86 + Expo SDK 57
- TypeScript (strict)
- Expo Router — файловая навигация
- NativeWind — стилизация через Tailwind CSS
- Zustand — управление состоянием

**Backend**

- Supabase — аутентификация и PostgreSQL
- Row Level Security на всех таблицах
- Node.js + Express — серверная логика, требующая привилегированного доступа

## Запуск

**Требования:** Node.js 20+, приложение Expo Go на телефоне.

```bash
git clone https://github.com/schoolprogramminggm-lab/syrjastary.git
cd syrjastary
npm install
npx expo start
```

Отсканируйте QR-код из терминала: на Android — через Expo Go, на iOS — обычной камерой. Телефон и компьютер должны находиться в одной сети Wi-Fi.

Если подключение не устанавливается:

```bash
npx expo start --tunnel
```

### Переменные окружения

Создайте файл `.env` в корне проекта:

```
EXPO_PUBLIC_SUPABASE_URL=https://ваш-проект.supabase.co
EXPO_PUBLIC_SUPABASE_ANON_KEY=ваш-anon-ключ
```

> **Внимание.** В приложении используется только публичный `anon`-ключ — защиту данных обеспечивает Row Level Security на стороне Supabase, а не секретность ключа. Ключ `service_role` в код мобильного приложения не попадает ни при каких условиях: операции, требующие привилегированного доступа, выполняются на сервере.

## Дизайн

Макеты шести экранов для обеих платформ находятся в `design_handoff_jastar_mobile/` — откройте HTML-файлы в браузере.

**Палитра**

| Токен | Значение | Назначение |
|---|---|---|
| `primary` | `#15B364` | основной акцент |
| `orange` | `#FB8B2D` | мероприятия |
| `blue` | `#1E63DA` | гранты |
| `ink` | `#0E1512` | основной текст |
| `surface` | `#F3F5F1` | фон |

**Типографика:** Space Grotesk (заголовки), Manrope (основной текст).

Все цвета берутся из `src/constants/theme.ts`. Hex-значения в компонентах не допускаются.

## Разработка

**Ветки**

```
feature/<название>   новая функциональность
fix/<название>       исправление
```

Прямой push в `main` закрыт — изменения проходят через pull request.

**Соглашения**

- Только функциональные компоненты, без классов
- Компоненты — `PascalCase`, хуки — `usePascalCase`
- Сетевые запросы только в `services/`, не в компонентах
- Каждый экран с данными обрабатывает три состояния: загрузка, пусто, ошибка
- Строки интерфейса выносятся в i18n, не хардкодятся в JSX
