# Handoff: приложение «Жастар» (SYR JASTARY) — редизайн, iOS + Android

## Overview
Мобильное приложение областного молодёжного ресурсного центра. Пользователь находит мероприятия, вакансии, гранты и программы, подаёт заявки, сканирует QR на входе, копит XP и Жас-коины за активность.

В пакете — два комплекта из 6 экранов: **iOS** (`Jastar-iOS.dc.html`) и **Android / Material 3** (`Jastar-Android.dc.html`). Контент, палитра и типографика идентичны; отличаются только платформенные оболочки и нижняя навигация.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, собранные в HTML**. Это прототипы внешнего вида и поведения, а **не production-код для копирования**.

Задача: воспроизвести эти экраны в целевой кодовой базе её собственными средствами и паттернами (SwiftUI / Jetpack Compose / React Native / Flutter). Если кодовой базы ещё нет — выбрать стек под проект и реализовать дизайн в нём. HTML/JSX-файлы нужны только чтобы открыть в браузере и посмотреть эталон.

Рекомендация по стеку, если начинаете с нуля: один кроссплатформенный код (React Native / Flutter) с двумя вариантами нижней навигации и оболочки, либо нативно — SwiftUI + Jetpack Compose, где Android-версия ложится прямо на M3-компоненты.

## Fidelity
**High-fidelity.** Все цвета, шрифты, размеры, отступы и радиусы — финальные, приведены ниже точными значениями. Воспроизводить попиксельно, подставляя компоненты целевой платформы.

Что НЕ проработано и требует отдельной итерации: экран магазина мерча (обмен коинов), экран деталей квеста, вход/регистрация, пустые и ошибочные состояния.

## Interactions & Behavior
- **Навигация:** нижняя панель переключает 5 корневых разделов, состояние сохраняется по вкладкам. iOS — плавающая панель поверх контента (контент скроллится под ней, нижний inset 110); Android — панель в потоке у края экрана (inset 96) + системная жестовая полоса.
- **Сплэш:** показывается до готовности сессии; спиннер 1.1s linear, пульс логотипа 2.2s, полоса 1.4s. Минимальная длительность 1.2s, далее переход на Главную (fade 200ms).
- **Появление контента:** карточки ленты — fade+translateY(8px→0), 240ms ease-out, каскад 40ms.
- **Нажатия:** iOS — scale 0.97 + opacity 0.9, 120ms; Android — ripple средствами платформы.
- **Категории-чипы:** одиночный выбор, мгновенная фильтрация ленты.
- **Поиск:** открывает отдельный экран с клавиатурой (в макетах не показан).
- **Квесты:** тап по квесту → экран деталей (не спроектирован); по завершении — начисление XP и коинов с анимацией счётчика и заполнением прогресс-бара.
- **«Обменять на мерч»:** ведёт в магазин (не спроектирован); кнопка неактивна, если коинов меньше минимальной цены.
- **QR:** запрос разрешения камеры при первом входе; успешное сканирование — зелёная подсветка рамки + хаптик.
- **Счётчик уведомлений** исчезает после прочтения всех записей.

## State Management
- `session` — авторизация, профиль (имя, инициалы, город, статус «Активист»).
- `activeTab` — текущий раздел нижней навигации.
- `feed` — список возможностей + `activeCategory` (все/мероприятия/вакансии/гранты), пагинация.
- `counters` — числа для сетки меню (18 / 42 / 24 / 9 / 6) и бейджа уведомлений.
- `gamification` — `xp`, `level`, `xpToNextLevel`, `coins`, `quests[]` (id, заголовок, статус, прогресс 0–1, награда XP/коины, состояние completed).
- `notifications` — записи с типом, временем, флагом прочтения; группировка по дате на клиенте.
- `scanner` — состояние разрешения камеры, результат сканирования.
Данные: ожидается REST/GraphQL-бэкенд центра; все числа в макетах — примерные.
